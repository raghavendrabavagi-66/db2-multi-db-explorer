# Page Override: Home

> Overrides `MASTER.md` for the home launcher only.

## Pattern

**Minimal Single Column** + **Enterprise Gateway** path selection.

- One hero, three service paths, no sidebar nav
- No KPI metrics, no hero banner, no quick-start expander
- Maximum whitespace (density dial: 2)

## Layout

1. Centered kicker + title + one-line subtitle
2. Three equal service cards (icon, title, short blurb)
3. Ghost **Enter →** button per card
4. Minimal footer line

## Anti-patterns (this page)

- No emoji icons
- No gradient hero blocks
- No metric strips or secondary CTAs
